# 攻坚计划交付包

版本：2026-09-22；目标仓库核验点：master@f51efe820。

建议先读《攻坚总计划.md》第1–5节与第12节，具体实施查23张任务卡。把《Agent执行指令.md》交给实施Agent；task-board.json为机器可读任务模板，所有父任务为PLANNED，不是完成清单。

| 文件 | 用途 |
|---|---|
| 攻坚总计划.md | 完整23项任务、优先级、实现顺序、验收、回退、测量纪律与首轮12个交付 |
| Agent执行指令.md | 可复制总控指令与首轮队列 |
| 核验记录.md | 本轮目标机只读事实与新发现，含具体源码入口 |
| task-board.json | 23张父任务卡、角色、波次、下一动作及无GPU替代任务 |
| run-envelope.example.json | 尚未批准的运行包络示例；不是可直接执行的配置 |
| 缺口_原始附件.md | 用户原始附件的逐字节副本，未修改其历史内容 |
| manifest.json | 交付文件SHA256与边界声明 |

本轮没有修改目标仓库、构建、运行测试、加载模型或启动GPU工作。阅读计划不等于授权执行真机实验；代码开发与实验默认启用分开。
