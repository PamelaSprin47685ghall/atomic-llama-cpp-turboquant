- 冻结时间：2026-10-10
- 版本标识：guardset-v1-20261010
- 适用范围：本机 5 × RX 6800，Qwen3.8-Flash-Next-GSQ-RCO-Q2_0，TP5 钢铁人基线与双边最优性研究

---

## 1. 宗旨与冻结声明

依据 [AGENTS.md](../../AGENTS.md) §2 与 §14 的明确契约，为防止“单题过拟合”（如针对中文“如何减肥”进行特化、微调裁剪、专家偏置、硬编码或牺牲通用语义），特设计本独立保护集（Guard Set v1）。

**正式冻结声明（红线）：**
1. **冻结性**：本保护集于 2026-10-10 起正式冻结。在揭示之前，所有题目、参考逻辑与评分准则不得增删、修改或放宽。
2. **零泄漏原则**：本保护集内容**严禁作为任何优化、调参、提示词工程、专家路由策略搜索、算子量化敏感度选择的输入**。在参数探索与性能迭代阶段，优化器与工程人员只能接触主测试题（中文“如何减肥”）及常规基础冒烟用例。
3. **不可伪造性**：不得事后根据模型的输出调整判定边界或修改合格容差。

---

## 2. 揭示条件与执行时机

本保护集绝不用于日常的算子微基准或探索性小测，其揭示与施测具有严格的因果时序：

1. **揭示节点**：仅当某个候选实现（例如原 Q2_0 BF16 LateBind、HC 坐标分区、强制 MMVQ 或特定 MTP 组合）已经通过了：
   - 单 site/单算子数值与状态对拍（无精度与逻辑破坏）；
   - 单任务无插桩自然 EOS pilot（端到端确实提速且输出合理）；
   并在准备启动正式的 8 个独立配对块（paired blocks）最终晋级确认**前刻**，由总控机制正式揭示。
2. **晋级前决门**：候选实现必须在独立无污染进程中执行本保护集全集：
   - 凡标为 `MUST_PASS` 的能力门与状态安全门，必须 100% 通过；
   - 出现任何一例 `MUST_PASS` 失败，立即取消晋级资格，保留原始错误日志，撤回候选，严禁进入钢铁人基线排名。

| 维度 | 主调参问句 (Workload Ω) | 独立保护集 (Guard Set v1) |

## 4. 判定规则三层门禁总览

所有测试均依次通过三层检验（详见 [rubric.md](rubric.md)）：

1. **能力门 (Capability Gate)**：
   - 检验数值重排、量化、截断或 LateBind 融合是否击穿了模型的本质推理能力。
   - 算术题有唯一机器数值答案；代码题要求语法无误且逻辑闭环；事实题要求客观精准。
2. **合理性门 (Rationality Gate)**：
   - 文本自然流畅，符合人类表达习惯；
   - 无明显的复读机式循环、退化崩塌乱码（repetition/degeneration）；
   - 无自相矛盾，无有害危险指引。
3. **状态安全门 (State & Resource Safety Gate)**：
   - **跨请求隔离**：后序独立请求绝不能读取、混合或泄露前序独立请求的私密上下文，证明 KV cache、recurrent state 与临时 scratch 正确归零与隔离；
   - **异常中断排空**：客户端断开（HTTP abort/timeout）后，底层 Vulkan buffer、epoch、reader/writer 锁必须干净释放，不得引发 GPU fault、显存悬挂或后续请求超时。
