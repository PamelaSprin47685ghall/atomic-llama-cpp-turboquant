# guard-08 质量判据

- 题目文件：guard-08.txt
- 类别：arithmetic（多步应用题）｜语言：中文｜期望长度：short

## 切题性

给出最终金额并带单位（元）；只列算式不给结论判 FAIL。

## 正确性

评审者须依据题目条件自行核算最终金额，再与回答数值比对；不一致判 FAIL。回答中出现的中间步骤若含算术错误，即使最终数值碰巧正确也判 FAIL——过程可复算是本题的主旨。

## 流畅性

表述清楚，计算步骤（若有）可读。

## 评审与记录

给出 PASS 或 FAIL，注明核算过程与比对结果；回答原文原样留存，不因失败删除。本判据不含预期答案原文；数值由评审者自行推导核对。
