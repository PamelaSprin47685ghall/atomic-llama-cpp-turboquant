# guard-03 质量判据

- 题目文件：guard-03.txt
- 类别：en-qa（自然过程解释）｜语言：英文｜期望长度：medium

## 切题性

回答须覆盖题目要求的三个部分：植物吸收什么、产生什么、为什么需要阳光；缺任一部分判 FAIL。回答语言须为英文。

## 流畅性

英文语法通顺、成段自然；大量破碎句或机械重复判 FAIL。

## 事实合理性

输入物质、输出物质与光能作用的表述方向须正确（评审者按基础生物学常识核对）；把反应物与产物的方向弄反判 FAIL。

## 评审与记录

给出 PASS 或 FAIL，注明所依据的具体观察；回答原文原样留存，不因失败删除。本判据不含预期答案原文。
