# guard-02 质量判据

- 题目文件：guard-02.txt
- 类别：zh-qa（历史文化）｜语言：中文｜期望长度：medium

## 切题性

回答须分别从商品贸易、文化往来、技术传播三个方面说明影响；任一方面完全缺失判 FAIL。只罗列名词而不说明"有什么影响"的不算合格。

## 流畅性

中文成文自然，三个方面之间衔接合理，无重复堆砌。

## 事实合理性

每个方面至少给出一个符合史实方向的具体内容；出现与公认史实明确相反的断言判 FAIL。评审者按常识与可查证事实自行核对方向；本判据不列答案清单。

## 评审与记录

给出 PASS 或 FAIL，注明所依据的具体观察；回答原文原样留存，不因失败删除。本判据不含预期答案原文。
