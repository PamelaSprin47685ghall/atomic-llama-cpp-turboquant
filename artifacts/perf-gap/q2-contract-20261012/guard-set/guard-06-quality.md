# guard-06 质量判据

- 题目文件：guard-06.txt
- 类别：code（编写函数）｜语言：中文说明 + Python 代码｜期望长度：long

## 切题性

回答须包含可读的 Python 函数（接受整数列表、返回中位数），并在代码后附简要思路说明；缺代码或缺说明判 FAIL。

## 正确性

评审者须人工核验代码逻辑：至少用一个奇数长度列表和一个偶数长度列表各走查一遍；偶数长度取中间两个数平均值的要求须体现在代码里。存在明显逻辑错误（如索引错误、未排序、奇偶分支处理错误）判 FAIL；语法错误导致不可读判 FAIL。

## 流畅性

说明文字与代码对应，中文自然。

## 评审与记录

给出 PASS 或 FAIL，注明所依据的具体观察（包括走查所用的示例）；回答原文原样留存，不因失败删除。本判据不含预期答案原文。
