# guard-09 质量判据

- 题目文件：guard-09.txt
- 类别：logic（真话／假话推理）｜语言：中文｜期望长度：medium

## 切题性

回答须给出明确结论（谁打碎了花瓶）并写出推理过程；只给结论不给过程判 FAIL。

## 正确性

评审者须自行完成推理、得出唯一结论，再与回答比对；不一致判 FAIL。

## 过程一致性

推理过程须自洽，并实际使用"三人中恰好只有一人说真话"这一条件；过程自相矛盾、或结论与自身过程不符，判 FAIL。

## 评审与记录

给出 PASS 或 FAIL，注明推理核对结果；回答原文原样留存，不因失败删除。本判据不含预期答案原文；结论由评审者自行推导核对。
