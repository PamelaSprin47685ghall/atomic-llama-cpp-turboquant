## 二、因 wedge/显示假象而需要**重开（reopen）**的结论

### R1【重开】"post-wedge = 单卡降级态"（我 13:00-13:20 的判断本身）

- **原结论**：card2 DPM 降级至 1200MHz，锁步拖慢全链 +4.98。
- **被什么动摇**：用户证实该卡 sysfs **从来显示 1200**（09-23 记录
  同款现象 + ALU 探针实测 17 TFLOPS 证明显示≠算力）。若 card2 一直
  如此且一直满速，则"降级"不成立，+4.98 需要新解释。
- **残余证据**：post-wedge profiled 日志 rank2 ready 527µs vs 其余
  373-384（1.38×）。但 G1/G2 历史 producer 表本就有 11-12ms/链的
  rank skew——**1.38× 是否异常需要与 pre-wedge 同口径对比**。
- **重开动作**：在 pre/post-wedge 两种状态下各跑一次同配置 profiled
  请求，对比五卡 ready 分布。若 rank2 skew 两态相同 → +4.98 另有
  来源（wedge/reset 的其它后遗症：PCIe 链路重协商、shader cache、
  内存时钟态）；若 skew 只在 post 出现 → 真实慢卡，但与 sysfs 显示
  无关，需 ALU 探针定位。
- **状态**：OPEN（P0-A 的"环境条件"表述降级为"机制未明的
  post-wedge 状态差异"）。
