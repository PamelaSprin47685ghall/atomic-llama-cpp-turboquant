# MM-R1 mindmap wire fixtures (protocol MM-R1, section 3).
#
# One document per record. `EXPECT` is the verdict the strict C++ parser
# (tools/server/server-rerot-mindmap.cpp) MUST return for the document, using
# the default limits:
#   depth 6, nodes 96, leaves 16, label 96 bytes, wire 16384 bytes.
#
# These fixtures pin the BYTE-level contract: the probe may emit any prefix of
# a legal document at any token boundary, so the same corpus also seeds the
# incremental prefix test (every prefix of a `complete` record must be
# `incomplete`, never `invalid`).
