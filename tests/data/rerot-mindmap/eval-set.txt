# MM-R1 frozen evaluation set (M13 scaffold)
#
# Fixed prompt set for the blind comparison. Rules that make it a valid
# instrument (not a convenience sample):
#
#   * 8 categories, 4 prompts each = 32 prompts. Category tags drive the
#     stratified analysis in the report, so a prompt's category is metadata, not
#     a hint the model can see.
#   * Development and blind splits are separated by PROBLEM FAMILY (the prompt
#     template the variants are generated from), not merely by different
#     numbers: a blind prompt must not be a development prompt with the digits
#     swapped, or the numbers stop measuring the reasoning being tested.
#   * `expected` is what an exact-match grader checks. It is only filled for
#     prompts whose answer is objectively verifiable. `rubric` categories are
#     graded by a blind human/LLM panel and MUST NOT be auto-scored by a
#     substring match against the final answer.
#   * Nothing in this file is allowed to become a few-shot example for the
#     planning prompt: a model that has seen these exact prompts is a different
#     experiment (planning blind test, E1) than this one (end-to-end, E3/E4).
#
# The prompt text is exactly what is sent; no system prompt is prepended, so a
# regression in the chat template cannot silently become a score change.
